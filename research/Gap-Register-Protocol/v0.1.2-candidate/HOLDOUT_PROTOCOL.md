# Private structural holdouts

The repository publishes test rules, a small smoke suite and additional adversarial calibration probes. All public material is discoverable and scores no comparative advantage. A pure digest lookup matches the 13 legacy outcomes over ten distinct views. At any fixed domain a complete correct decision table can be extensionally equivalent to an algorithm. A black-box experiment cannot prove the absence of hard-coding or distinguish all implementations with identical outputs.

## Prospective assessor plan

1. Nominate an independent custodian and a second reviewer for the sealed corpus. In a separately controlled private workspace, build both truth histories and neutral projections. No participant write/read access to the assessor checkout, generator configuration, seed, inputs, exact expected verdicts, keys or raw scoring logs. Do not upload private data to the public PR, Actions or public artifact storage.
2. Preregister a target of **48 distinct evaluable structural views** across K1–K3 (16 each), plus six opposite-truth twin executions and at least three independently reviewed premise attacks. Per family reserve at least three lawful clearances, three constructive conflicts, three open evidence views and three invalid timelines. Score conditional and actual truth separately. If an axis is unrealizable in this grammar or coverage falls short, stop and document the feasibility problem before participant implementation.
3. Vary geometry, not only ID names: role reversal with different producer, alternate dynamic branch and multi-hop read, lawful consumed older version, before/equal/after ordering, threshold vs layout, surviving vs neutralized versus unbound successor, open vs false coverage and positive under open dependency scope. Use paired structural reversals of outcome. Validate with both reference models, manually check all expected cross-cells and reject accidental contradictions except intended invalids. Renumber IDs independently of timing. Exclude exact **and** alpha/order-normalized public matches from the 48 unseen views using topology, event-kind sequence, relative order, fields, channel, version lineage and read tree as structural discriminators. The assessor records rejection/acceptance counts per axis. Approval requires demonstrations that public and renaming-only lookup mutants with a default fallback fail on the held-out set.
4. Seal inputs, truth, scores, logic versions and one packaged manifest in separately controlled encrypted custody. Keep exact small-domain hashes, per-case results, seed, salts and grounds for accepted cases private. Public timestamp commitment, if needed, is a verified signed receipt over a high-entropy randomized encrypted bundle, or a hiding commitment with a cryptographic secret held by the custodian. Bare hashes and publicly salted hashes of enumerable cases or seeds reveal small-domain contents. The public record can state plan/version and custody milestones.
5. Freeze contestant artifacts before revealing any private inputs. An assessor-side runner gives one canonical request per view inside a network-restricted isolated container. Truth, expected labels and the scorer stay outside the participant container. Record audited allowed access. Keep actual rerun and comparison artifacts access controlled. Release only aggregate/sanitized evidence until artifacts are frozen, all scoring is done, and an independently agreed disclosure occurs. Re-run private validation only from the sealed preregistered bundle.

This protocol targets public-corpus lookups. Generalizing rules, unexpected defaults and table-driven algorithms may still agree on unseen rows. Report discriminating ability only through actually executed control mutants under isolation. The current repo has no private corpus, no assessor deployment and no completed private trial.

# Criteria fixed before running the comparative pilot

Use the predeclared S01–S12 labels and expectations. A/B/C/D consume the same governance evidence and authorization flag. A uses the declared distinct roles, B additionally uses P-01 event/binding validation and authenticated snapshot matching, C adds witnessed and upper residual effects, D only attaches diagnostics. An authenticated same-identity witness may block; a possible remainder alone may cause a hold.

Technical success requires identical serialized C/D governance outputs, the expected named outcomes, cross-seed deterministic corrected outputs, and agreement with a separately written oracle over the finite enumerated and random inputs. Structural invalidity, substantive support and governance clearance are measured independently.

Diagnostic relevance within this pilot requires at least one governance hold with certified outcome insensitivity and at least one hold with two admissible different-outcome witnesses and an exact evidence query that separates all outcome classes. A certified constant case has an empty scientific query. Compare the minimum set of modeled substantive facts with asking for all of those facts, keeping all governance requests in both. Report exact absolute counts and distinguish this modeled comparison from a measured organizational cost saving. Synthetic contrast alone cannot establish economic or scientific value in deployment. A null result remains admissible.

Named tests precede finite enumeration, then deterministic randomized runs. Timing is an isolated single-process invocation benchmark and does not measure certificate issuance. Static line counts and logical attestation counts are implementation proxies.

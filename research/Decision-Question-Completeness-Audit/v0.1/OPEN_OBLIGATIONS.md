# Decisions and open obligations

| Question | Decision | Boundary |
|---|---|---|
| Technical reproducibility | GO | Pinned original pilot and new fixtures, verified hashes, two numerical solvers and two evaluator implementations. |
| Formal viability | CONDITIONAL GO | The indistinguishability result is general for a fixed projection; positive completeness is relative to an independently justified scope, bounds and version binding. |
| Demonstrable detection of missing questions | CONDITIONAL GO | Concrete externally evidenced omissions were detected. Input-only general detection is impossible by the exhibited pair. |
| Practical value beyond C+S | NO-GO in the tested comparison | No added diagnostic information on identical evidence. Net value of an integrated workflow in actual adjudication is UNDETERMINED. |
| Normative adoption | NO-GO | Retain the evidence as a scope-bound audit. Do not expand this branch into a mandatory module on these results. |

Use a version-bound procedure and independent requirements/dependency inventory, check the submitted implementation against it, and run joint sensitivity over verified admissible uncertainties where the outcome matters. Apply P-01/HR-1 separately where versioned effective control and historical gaps really affect permission. Withhold a conclusion when that evidence is missing. This is a minimally sufficient *conditional* combination for the benchmark class, not a universal workflow warrant.

Open: trace dynamic dependencies in real executable procedures; validate authorized scope with multiple independent evidence channels; assess correlated or continuous uncertainty with a sound domain; measure time and error against independent reviewers using ordinary methods if a future, concrete need warrants it. No empirical claim about field performance or certificate cost follows from seeded finite cases or synthetic NIST omissions. Original sources and decisions are anchored in the published branches.

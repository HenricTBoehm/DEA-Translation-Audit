# Independent adversarial protocol review

**FREEZE NO-GO for v0.1.1.** A fully reproducible fixture check and a feasible comparative design are separate achievements. The casepack tests correctly expose conditioned evidence failure. The current design cannot yet discriminate a substantive security advantage from stipulated materiality, better issuer evidence, unequal custom work, or a lookup over a public test set.

## Executed evidence

- Archived 10 self-tests passed, original report reproduced bytewise. This is package consistency.
- A separate executable reference reconstruction matches six canonical worlds and 13 ordinary executions, including 3 CLEAR, 3 CONFLICT, 6 UNDETERMINED and 1 INVALID. It verifies all three twin projections and the separate X-TRUST attack.
- Proofless positive accusations, always-deny, always-permit and always-invalid fail the review scorer. A digest-lookup attack passes 13/13 of the public corpus.
- Isolated adversarial probes expose the missing-vs-contradictory event problem, credential validity omission, and material/immaterial control boundary. The thawed successor binding and partial reset cases show exactly what effect evidence must be supplied.
- Comparator implementations, runtime equivalence, human approval and operational evidence validation remain **NOT EXECUTED**. The audit does not infer a new advantage for Decision Stability or evaluate a default architecture as if it were a strongly configured established composition.

## Proposed subsequent experiment, conditional on a documented freeze

Constrain the scored comparison to one versioned binary evaluation with verified reads, one production scope, one material threshold or standard, and bounded traces with independently recorded key validity and exact residual effects. Keep other disposition gates fixed. Retain K1–K3 as smoke tests, plus independent held-out neighboring cases for open scope, actual material vs cosmetic effect, and ordered revoke/modify/reset. Use the same evidentiary semantics and proof checker for D0, D1 and at least one carefully configured established gate plus the shared predeclared provenance/validity functions. Run a consumer-only comparison first with identical neutral evidence. In a separate acquisition stratum, evaluate an established evidence-provider composition on matched raw visibility, trust and budget; measure capture and issuer obligations separately. Include the X-TRUST attack as an issuer-integrity test. No full-architecture equivalence or superiority claim from these bounded fixtures. A documented null result is an acceptable endpoint.

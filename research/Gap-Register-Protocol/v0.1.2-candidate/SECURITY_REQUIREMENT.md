# SR-1 · External material integrity

**Selected requirement.** For this assessment, forbid one canonical principal from controlling both an admissible production input to the sealed result and a materially usable criterion actually consumed by the bound evaluation. Protect an independently fixed assessment from self-serving choice on both sides of the decision boundary. This is a substantive integrity policy for scientific measurement. Signer independence alone is an intentionally different policy. Agreement with SR-1 measures conformance to a chosen requirement; independent external approval of its applicability and utility remains open.

Production leverage means an authorized route to choose a score in the supported range before seal. Signing a fixed-output operation is not such leverage. Evaluation leverage requires a verified actually consumed role and exact version, and either an admissible alternative version before binding or a surviving earlier change on the consumed channel. This is a capability relation. Report separately whether a material write occurred and remained effective. Neither route establishes intent, intentional tampering or a different decision in the observed run.

Use scores `{0,1,2,3}`. An evaluation accepts iff its score is at least the sum of the thresholds on its uniquely consumed versioned nodes. Between one and three nodes are used, each with threshold 0 or 1. Materiality is existential over admissible scores, while holding the other consumed values and the evaluation policy fixed. If those other thresholds sum to s (0–2), score s distinguishes this threshold's 0/1 alternatives. An observed outcome may remain unchanged at its actual score. An omitted extra dependency cannot undo a verified positive on a known path within this domain, because the same existence argument still holds with s recomputed. Layout is outside the function. Broader policies banning all control of a file or every protected field irrespective of outcome effect are outside this study.

A reachable recorded runtime read uses the mandatory criterion role. An optional dynamic subtree matters when actually selected; static inventory alone establishes neither selection nor exhaustive coverage. IDs identify immutable versioned contents. Modelled influence is by a restricted channel and key; signing-only, collusion, key sharing, arbitrary code/selector substitution and policy modification outside the fixed policy are outside the profile.

| Probe | Neutral observation | SR-1 consequence when producer has leverage |
|---|---|---|
| M1 | Consumed threshold writable at bind, or material write survived | Positive with a replayable shared-principal path |
| M2 | Layout write at the same consumed artifact | No material route from this write |
| M3 | Dynamic direct or indirect threshold actually consumed | Relevant when observed; missing capture leaves negative coverage open |
| M4 | Production signer with fixed score and no production right | Identity alone does not supply an SR-1 witness |
| M5 | Earlier threshold change survives later right/key loss | Positive if that exact effect is still consumed |

The forward transition evaluator in `oracle.py` identifies the typed effect. `crosscheck.py` independently queries preceding rights and follows lineage from bound version back to source. It also tests threshold materiality by explicit counterfactual score evaluations.

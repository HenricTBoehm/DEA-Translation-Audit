# Evidence boundary and wire contract

Stratum A sends one canonical UTF-8 JSON object per request. The only top-level keys are `history_closed`, `dependencies_closed` (both Boolean), and `events` (array with exactly the allowlisted fields for the event kind). Wire encoding uses sorted map keys, no insignificant whitespace and deterministic order of canonical event records. Preserve authenticated contradictions and null ranks. The adapter may not provide attempt labels, row indices from the scorer, reference-world or expected values, access to assessor code/storage, request timing keyed to outcome, or data outside the declared fields. Synthetic public IDs are convenient numbers and can coincide with rank. Private IDs must be permuted independently of rank/outcome within the finite grammar. Unknown event types and metadata outside the wire shape are adapter/profile errors, scored as NO_DECISION and separately logged. Authenticated contradictions within scope, such as rank 16, are passed intact.

In the synthetic prototype, admissible signed-event facts are stipulated as authenticated by a neutral adapter. Real signatures, trusted times and completeness are outside the JSON encoding. The production adapter must record issuer identity, exact content identity, verification result, permitted namespace, time, receipt scope, covered event kinds and proof of collection before setting either closure bit. Intake separates authenticated facts, unauthenticated reports, unsupported values, absent records and asserted coverage. Unknown whole facts remain withheld with an open scope and explicit assessor log. Closure bits carry the same conditional semantics for each participant. No party receives actual premise correctness or reference truth as a hint.

One receipt covers the complete relevant non-read history through commit (including rights, versions, calibration and positive-witness scope as applicable). Another covers every performed criterion read and path at the bound policy/version. The closure assumption is tied to the single submitted attempt. Positive responses cite actual evidence IDs; clearance relies on scope and an independently assessed receipt. Independent truth concerning the correctness of a receipt remains an S4 assessor finding. A falsely authenticated closure may produce a false actual release.

For each contender record the exact adapter hash, canonical request/output digest and immutable native transcript. Review mapping field-by-field and challenge absence in profiles where synthetic data are held back. Each byte-identical view must give the same normalized result in a deterministic participant, regardless of actual truth. Check remapping/isolation using assessor-generated requests and disallow extra access logs or side channels. The published `wire()` checks only serialization/shape. Translation adapters, deployment isolation and external receipt validation remain NOT EXECUTED.

Stratum B starts from specified raw simulated records and independent capture channels shared by all parties. Run capture/transcript assembly at the same authorized access and deadlines. Pre-run enable identical sensors, issuer availability and infrastructure. Log successful, failed and unattempted acquisitions and the origin of each supplied assertion. Compare capture, verification and disposition separately from the identical wire of Stratum A.

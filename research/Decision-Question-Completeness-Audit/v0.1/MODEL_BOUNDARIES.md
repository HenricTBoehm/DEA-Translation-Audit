## Indistinguishability theorem

Let an observed input be a projection $E=\pi(w)$ of a reference situation $w$. Let $M(w)$ mean that the projected input lacks a decision-relevant factor of the reference situation. If two situations $w_0,w_1$ have $\pi(w_0)=\pi(w_1)$ and $M(w_0)\ne M(w_1)$, then no total Boolean test of $E$ alone both soundly and completely recognizes $M$ over a domain containing both. A deterministic test must return the same value on the common input. For a randomized test the output distribution is the same, so neither value can be correct with probability one in both situations. An abstaining test can report insufficient evidence.

Q-B0 and Q-B realize this witness with distinct examiner-owned situation tables and **byte-identical** observed records. One situation is constantly ACCEPT; the other allows REJECT and ACCEPT, depending on an entirely absent factor. The input includes a claimed completeness flag. Independent evidence identifying the factor appears only in the scope-review input. Equivalence of observed labels does not authenticate the real implementation or its environment. A verified executable, effect abstraction or inventory can exclude this pair for a specified scope. This changes the available evidence, so it does not contradict the theorem.

## What can be certified

Fix the protected attempt, actual evaluation procedure, binding versions and an independently justified covering set of applicable worlds. An exact finite census can establish that the outcome set is a singleton. A sound overapproximation with one outcome also suffices, provided the actual admissible set is nonempty; a counterexample to stability needs two genuinely admissible worlds. The code compares exact finite declarations or explicitly marked samples. It implements neither general proof of sound abstraction nor independent certificate issuance.

The proposed bounded question check is an inventory comparison against a separately established, version-matched procedure or runtime evidence: look for absent factors, missing effects, omitted bindings and known excluded worlds; then rerun ordinary analysis on a corrected candidate. A discrepancy establishes a local defect. No discrepancy establishes agreement with the provided source in the audited scope. An unmatched source yields SOURCE_SCOPE_UNVERIFIED. The check cannot infer all hidden variables, prove a distribution, or issue a disposition from a successful fit.

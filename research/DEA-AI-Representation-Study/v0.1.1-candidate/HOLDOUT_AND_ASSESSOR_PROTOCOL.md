# Holdout and assessor interfaces

O1 and O2 require reconciliation with the original protocol's exact definitions after intake. Pending that, use these conservative gates: O1 independently replay and cross-check each locked private case and its complete certificate ledger; O2 custody/security review of item novelty and evaluator isolation plus attempted leakage probes. Neither executed. No actual H was created.

Custodian maintains a private canonical evidence ledger and a separate assessor-only world and certificate ledger. Generate structurally different cases and attest non-duplication against public P/G by normalized structure (event types, order constraints, version/rights/dependency graph), not renaming or secret IDs alone. A second assessor independently checks replay, scope, admissible alternatives, labels and contradictory/missing evidence handling; lock mapping and handle discrepancies before participant output. Keep membership, salts/keys and low-entropy cases private. An unkeyed public hash does not hide small enumerable inputs. Protect raw artifacts in authorized private storage with access logs and separation from public GitHub.

Proposed v1 boundary:
1. Custodian export to runner a randomized schedule and exact prepared prompt bytes keyed by opaque run token. No world, certificates, item source names, semantic labels or answer hints. The common evidence portion is separately digested. Authorize least-privilege access and record who can read each transfer. Test the transport with public fixtures.
2. Runner returns only opaque token, raw answer, actual settings and request provenance, terminal outcome and retry ledger. Participant sees prompt only, in fresh context. Runner never imports public build/items.jsonl for private runs.
3. Offline assessor joins a separately authenticated scheduled catalog of tokens and verified certificates with response records. Unexpected/duplicate tokens fail closed; missing scheduled records remain in the denominator. scoreScheduled is the tested public prototype for this join, not a deployment with authorization. Private worlds are linked only inside assessor storage and cannot change the justified verdict. Keep stable per-arm and across-run evidence hashes in authorized logs. Independent reviewer checks negative controls including hidden answer markers and evaluator file access before granting custody approval.

Do not expose first-run holdout items to calibrate prompts, set margins, choose models or fix proof handling. If a material defect is discovered, mark the affected confirmatory run unfit and seek fresh, separately authorized material for any amended protocol. H custody and end-to-end isolation NOT EXECUTED.

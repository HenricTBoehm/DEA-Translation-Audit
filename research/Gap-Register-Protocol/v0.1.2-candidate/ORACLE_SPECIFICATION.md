# The two oracles and constructive proofs

**Ω_truth(w).** The assessor has the concrete complete ordered synthetic history including selected reads and independent premise assessment. A malformed or unauthorized trace yields MODEL_INVALID. A valid trace yields CONFLICT exactly when SR-1 has a shared material production and bound evaluation path; otherwise NO_CONFLICT. This label is never an engine input. A historical write and a present capability may both support the same conflict.

**Ω_just(E).** The assessor replays only the admissible verified evidence view under the recorded closure claims. Process authenticated contradictions first. Then require complete scoped history and verified ranks for a definite conflict or clearance. A positive returns a principal, its production grant and operation, an exact consumed version and a typed path using the relevant right or past write together with bind and read. Verify those event IDs and replay the path and same-principal linkage. A candidate cannot substitute the expected label or an unauthenticated signed claim. A proof may cite any valid path, while the executable report emits the first in canonical order. A future equivalent exhaustive implication requires assessor approval and its own bound justification before profile freeze; the current candidate checks the constructive route only.

CLEAR requires sufficient dependency coverage **and** scoped history replay closing the positive alternatives. If that coverage is merely asserted, the reported consumer verdict is model-conditional; S4 independently marks the assertion and actual premise in the synthetic setting. Evidence with a proved positive path can remain globally open. Missing positive evidence is insufficient for clearance, and an unresolved collection is insufficient for INVALID. UNKNOWN facts excluded at intake are distinct from authenticated contradictions.

X-TRUST creates valid projected facts byte-for-byte equal to K1-C, while its actual complete world contains a material extra dynamic read. Ω_just gives conditional CLEAR under the false coverage claim, Ω_truth gives CONFLICT. This conditional result cannot establish real-world independence; the bytes cannot determine which world actually obtained. The assessor scores the false premise and truth-relative release separately. External capture or independent evidence can break the indistinguishability.

The transition oracle replays ordered events with live grants and immutable snapshots. The independent checker starts at each observed read and queries prior events and backwards version lineage, calculating materiality by enumerating scores. It compares complete traces and checks finite rank realizability independently on the bounded rank probes. It does not simulate authentication or exhaustively decide open-history validity. The two implementations share the frozen experimental grammar and the test data, but neither takes an expected verdict to compute a result. This is an internal AI-developed cross-check, distinct from an independent human approval.

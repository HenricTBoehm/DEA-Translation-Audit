## Reproduce

Use CPython 3.12.14 on Linux x86-64, Bash, Git, tar and sha256sum. The new audit includes verbatim public ASCII datasets with raw checksums. Their byte-preservation attribute disables text conversion. Fetch the pinned source branches if the objects are absent.

```sh
git fetch origin research/precision-amendment-p01 research/hr1-stability-independent-v01
cd research/Decision-Question-Completeness-Audit/v0.1
bash verify.sh
# Optional original-pilot reexecution requires the authenticated original HR-1 ZIP.
bash verify.sh /absolute/path/to/dea-hr1-history-remainder.zip
```

verify.sh checks pinned source assets and the report fingerprints. It reads the exact Python modules from the two published Git trees, then reruns the independent comparison under hash seeds 0 and 42 and compares both result files. With the optional ZIP, it also executes PR #10's original verifier after checking the inherited pilot files. Statistical benchmark values, world tables, comparisons and machine decisions are deterministic. Execution timings differ across runs. The pre-fit case choice was committed separately before public dataset retrieval. The benchmark study uses NIST's documented procedure and observed data with explicitly synthetic omission scenarios.

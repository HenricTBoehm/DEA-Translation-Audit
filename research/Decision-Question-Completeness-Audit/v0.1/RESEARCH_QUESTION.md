# Decision-relevant question completeness audit v0.1

When can missing decision-relevant questions be detected, and does the implemented DEA Decision Stability diagnostic add to conventional exact multivariate sensitivity analysis on the same evidence? The frozen protocol and pilot are PR #8 and #10. This is a bounded, non-normative audit.

## Plan fixed before case-study execution

Select NIST StRD Norris (linear ozone-monitor calibration with intercept, 36 observations) and Pontius (quadratic load-cell calibration, 40 observations). Both publish observed data, an explicit fitted procedure and certified coefficients. Different required features (intercept and curvature) exercise two forms of implementation omission. These are reproducibility benchmarks with public inputs; no actual governance problem at NIST is presumed.

Keep each NIST response, predictors and certified target fit fixed. On each benchmark, independently compute the full fit and the fit obtained by omitting one required term (Norris intercept, Pontius quadratic term). Test acceptance of a candidate coefficient vector against every certified coefficient, using a pilot-defined maximum absolute relative error of 1e-8; absent term coefficients are zero. Predetermine both variants before fitting. Treat them as two possible facts about which implementation produced a candidate, under one unchanged validation rule, and label all injected metadata uncertainty and omissions. The NIST program choices themselves are documented. Use exact rational normal equations and an independently implemented, scaled QR solve; confirm that the certified full fit passes in both implementations.

Compare C, C+S and D using the same inputs, protected-version scope, decision rule or observed outcome table, claimed coverage and available evidence. C+S performs exact joint input variation and uses opposite-outcome pairs to find a minimum sufficient set of facts; it is allowed to consume evidence of finite coverage just as D is. D runs the pinned PR #10 diagnostic. Compare ordinary procedure/documentation review with the proposed additional audit. Test whether identical observed inputs can hide different ground truth and include an interaction fixture to distinguish joint variation from a one-at-a-time sweep used only as a side demonstration.

Timing units: log actual network receipt or evidence prompts, measured computation for checks and witness/receipt preparation, and a separate reproducible execution microbenchmark. Analyst labor, independent participant burden and production certificate cost require observation; report NOT EXECUTED where unavailable. Use absolute counts with denominators. Technical success requires complete pilot replay, expected behavior in Q-A–H, independent numerical baseline agreement, pairwise C+S/D comparison and unchanged governance by attachment. A null result for D over C+S is admissible. Biomedical, actual institutional authorization and normative claims are outside scope.

Sources selected before fitting: [Norris specification](https://itl.nist.gov/div898/strd/lls/data/Norris.shtml), [Pontius specification](https://www.itl.nist.gov/div898/strd/lls/data/Pontius.shtml).

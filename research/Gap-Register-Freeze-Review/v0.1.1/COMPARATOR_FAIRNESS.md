## Classification test

Classify the **algorithm and data supply**, not the file format or language. Use the highest applicable level for the gate and its producer separately, and preserve component provenance. L0 is released feature behavior with only ordinary attachment to the system. L1 selects and composes documented predicates on the declared input schema; e.g. compare directly provided canonical principals and enforce required attributes. L2 joins unchanged, independently available components through a documented schema-preserving adapter, exposing both runtimes, trust assumptions and cost. L3 introduces synthetic metadata inference, new replay/closure, effect attribution or certificate issuance, irrespective of language or container. A previously released generic primitive (e.g. reachability) can be L1 on neutral edges under an appropriate configuration. Encoding history state, resets and control attribution to construct those edges by custom rules is L3 for that part. A released producer of authenticated edge claims can be an L2 source if its scope and trust profile really match.

Avoid overclaiming: an engine's ability to encode a decision table does not mean it independently captures or verifies the relevant evidence. If a future test fixes a restricted observation function, an indistinguishability argument can establish a limit of that profile. It does not constrain a richer vocabulary, a trusted external observation or all configurations.

Holdout minimal axes: version-mismatched evidence, material vs cosmetic on same file, a dynamic actually consumed dependency, required field missing versus verified contradictory order, evidence absent vs false certificate, trusted positive witness despite global coverage open, revoke before write versus effect after revoke, partial reset versus exact neutralization and successor. Select the smallest balance that distinguishes these gates. Rename IDs and principals metamorphically, and vary actual structures rather than only labels. Corpus publication and implementation must account for who can read the hidden truth. The audit's lookup is a simulated scoring counterexample, not a comparison implementation.

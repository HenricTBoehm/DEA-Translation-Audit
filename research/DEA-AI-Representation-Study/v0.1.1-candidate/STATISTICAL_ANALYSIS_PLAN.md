# Statistical analysis plan · prospective draft

Primary loss is binary wrong_verdict, C minus B as an absolute paired risk difference. Lock it now. There is no switch after A-only calibration. If the observed error rate on public material suggests a floor, continue only as an exploratory logistics pilot. Small effects at a floor are evidence limitations. Primary estimand uses one prospectively chosen model and one scheduled sampling index per independently generated evidence family; other fixed models/repetitions are diagnostic. Model choice and budgets are locked before any private access. Select family representatives prospectively, blind to responses. No counting twins, mutations, repeated calls or models as independent samples. If a corpus is purely fixed/synthetic, report its exact finite-panel rates. Generalizing with the intervals below requires independently sampled families under a declared draw process. Report quota-specific strata separately unless a valid weighted cluster analysis has been preregistered. Shared families create dependence across contrasts, which the multiplicity bound accommodates.

Primary minimum useful improvement is 5 percentage points. Candidate safety margins (must be ratified before sampling) are +2 points for unjustified_release on non-RELEASE, +2 for unsupported_conflict on all scheduled, +2 for false_invalid on non-INVALID, +5 for missed_invalid on INVALID and +5 for false_hold on RELEASE. Each adverse increase is C minus B. Primary, five C–B guard intervals, B–A wrong_verdict, C–C′ wrong_verdict and C–B lack of verified justification form one nine-comparison family at 95%. All other diagnostics, optional controls and models are separate exploratory tables. No best-model pooling or mixed-effects fit with three model levels. Preserve paired eligibility and report denominators, confusion matrices, discordant counts and missingness by condition, model and item family. Explain timed-out or truncated responses. Unexpected missing labels invalidate that item for both arms and require blinded correction/replacement before comparison; absent response is wrong, not complete-case deletion.

For each comparison, bound both directional discordance probabilities with two-sided exact binomial intervals. Each tail has 0.05/(4×9) error allocation. Invert their difference to obtain the C-minus-B bound. Bonferroni provides at least 95% family coverage under the specified independent-family sampling design, without assuming independent directions/contrasts. Boundaries and complete separation need no logistic fit; finite data can yield wide intervals even at zero discordances. Zero eligible pairs returns not estimable. With repeated sampled outputs publish itemwise and modelwise results, no generic model-population inference. [Exact binomial intervals](https://www.itl.nist.gov/div898/software/dataplot/refman2/auxillar/exacbici.htm).

- Useful advantage requires primary upper bound below −5 points and every safety upper bound below its margin. A demonstrated primary improvement that does not clear the guards receives no advantage decision.
- Noninferiority requires primary upper bound below +5 points and all guard upper bounds below their margins. Practical equivalence requires primary interval inside ±5 points and all guard intervals inside their respective symmetric margins. A statistical directional difference smaller than the practical threshold can coexist with equivalence.
- Disadvantage requires primary lower above +5 or a safety lower exceeding its positive margin. Demonstrated benefit on one metric and demonstrated degradation on another is a trade-off, reported as such.
- Otherwise report inconclusive for the applicable claim, separately reporting every established bound. Absence of significance is not equivalence.

## Size, feasibility and stop rules

Retain authenticated ranks and IDs 0–15. At most 16 distinct valid event positions. A deliberately malformed input can test the existing grammar but must not extend it. Replace H-long with fixed, structural strata: nested reads, version changes with no-op/layout decoys, partial independent resets, revoke/history carryover, unresolved ranks, multiple supported witnesses. Keep the strata locked and pilot them against original limits. Do not confuse added token bulk with semantic difficulty. Structural novelty and oracle validation precede private allocation.

The hosted planning prototype simulated 2,000 independent paired families samples per grid cell. Directional probabilities (C worse 0.02, C better 0.12) yield 494/2,000 demonstrations at n=600 and 1,590/2,000 at n=1,200 for the primary criterion alone. Safety gates only reduce joint power. A stronger 0/0.15 scenario illustrates non-uniform power; 0.05/0.10 lies at the practical threshold itself. At zero discordances with 240 eligible families the simultaneous upper bound is still 2.70 points, too wide for a 2-point safety gate. Determine power for all six decision criteria jointly using independently justified rates, class mix and clustering before confirming. This grid is planning data, not observed model performance.

Planning floor 600 independently sampled families and provisional cap 1,200, subject to increasing budget before study or abandoning confirmation if power is below 80% or the narrowest safety endpoints lack eligible families. Even 1,200 is borderline for the above scenario. No interim effect monitoring or expansion after condition labels/results become visible. One model, four arms, one answer per family costs 2,400–4,800 calls at those bounds. Three models with five repeats would cost 36,000–72,000 calls. Calculate actual spend with frozen input/output token distributions, per-provider prices and retry ceiling. No current monetary estimate without a model roster and tokenizer counts. Stop for unavailable custody, failed semantic validation, unaffordable prospectively estimated budget, structurally inadequate item pools or critical deployment drift; diagnose separately. The bounded first pilot recommendation is one model, 24 public families, B/C, one answer per face (48 calls), with no inferential claim. Use it only for transport, token/time, score failure modes and response-schema burden.
